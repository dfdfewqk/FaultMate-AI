# FaultMate AI P7.2 — 1단계 수정 결과 (2026-10-30)

## 목적
설비 고장 현장에서 원인/사례 ID를 모르는 사용자가 설비 종류와 증상만 입력해 기존 근거 사례를 찾고, 그중 하나를 **직접 선택**하게 개선.

## 변경 파일
- `web/index.html`: 증상 기본 노출, 관련 사례 추천·직접 선택 영역 추가, 알람/모델명은 접힌 영역 유지.
- `web/app.js`: 기존 P2 `selection_required` 응답 사용, 350ms 디바운스, 취소·오래된 응답 무시, 설비/증상 변경시 기존 사례·질문·진단 결과 무효화, 긴급 위험 중 요청 차단.
- `web/style.css`: 추천 결과 목록·버튼 스타일, 키보드 포커스.
- `faultmate/app.py`: P7.2-S1 식별자/버전만 수정, 진단 계약·엔진 미변경.
- `tests/test_p7_2_step1.py`, `tests/browser_step1.py`: 새 회귀·브라우저 시나리오.
- `tests/test_p7_1_debug.py`: 최신 릴리즈 식별자 기대값 갱신.

## 중요한 적용 범위
- 추천은 미검증 텍스트 키워드 기반으로 기존 7개 교육용 사례만 찾아줌. 원인, 확률, 모델 적합성은 예측하지 않음.
- 사용자가 추천 사례를 직접 선택해야 원인 후보 검토 버튼 활성화.
- 알람 원문과 모델명은 화면에 참고용으로 보존하지만 추천·후보 순위에 사용하지 않음.
- 사례 불일치 시 근거 없는 대체 사례나 새로운 자동 고장 확정 없음.
- DeepSeek 원격 API, ML 실측 학습·실제 Windows 환경 검증은 완료되지 않음.
- P7.1 원본 ZIP은 그대로 보존함.
