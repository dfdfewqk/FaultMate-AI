## 원본 파일명에서 관찰된 3부하 묶음

| 구분 | 이름 코드 그룹 수 | 원본 MAT 수 | 저자 논문에 제시된 실물 시제품 수 |
|---|---:|---:|---:|
| 정상 `N4~N8` | **5** | **15** | **3** |
| 손상 `I,O,B,IB,IO,OB` + 규격 | **28** | **84** | **27** |
| 전체 | **33** | **99** | **30** |

- 각 이름 그룹에는 서로 다른 부하 0/200/400W 조건의 파일 3개가 있음. 부하가 다르다고 독립 실물 베어링 3개가 아님.
- 원본 파일명만으로 같은 베어링이 두 규격 코드 사이에서 교환되었는지, 손상 전후 동일 물리 시제품인지, 원저자 통계가 단순 표기 실수인지 판단할 수 없음.
- 따라서 **파일명 그룹 33개 = 검증된 독립 실물 33개**라는 결론도, **논문 30개 = 파일별 인증된 물리 시제품 30개**라는 결론도 안 됨.
- 아직 확인된 물리 시제품의 **저자-파일 대응표는 0건**. 해시 확인과 물리적 샘플 동일성은 다른 문제.
- 신호 길이가 512000샘플이 아닌 원본 18개도 원래 길이 그대로 보존·표기. 신호를 512000개로 임의 증식/잘라내지 않음.

## 원저자에게 확인해야만 해결되는 항목

원저자에게 다음의 **구체적인 답변**을 받아야 물리적 ID-원본 매핑을 확정할 수 있다:

1. `N400/N500/N600/N700/N800.mat` 다섯 규격 정상 코드가 있는데 원저자 논문의 **정상 시제품 3개**와 어떻게 대응하는가? 어떤 3개가 실제로 고유 물리 개체이고 나머지는 무엇인가?
2. 손상 상태 원본 이름 그룹이 **28개**인데 논문에는 **27개 손상 시제품**이라 기록됐다. 중복 또는 복수 상태에서 측정한 시제품이 있는가? 있다면 각 실물 시제품 고유 ID와 전체 파일/부하 대응표를 요청한다.
3. 정상-손상 사이에 동일 베어링의 재가공·재사용이 있었는가? 있다면 독립 검증용 train/test 시점 분리에 관련된 전체 대응표가 필요하다.
4. 논문과 Mendeley v3 중 어떤 자료가 최신이고 최종적인 실물 베어링 수의 근거인가?
