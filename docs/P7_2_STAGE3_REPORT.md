# FaultMate AI P7.2 — 3단계 결과 화면 간소화

기준: P7.2 2단계 ZIP의 코드. 이전 단계 수정본 및 원본은 변경하지 않음.

## 변경 범위
- web/app.js: 원인 후보와 간단한 이유, 먼저 확인할 기존 기록 2개, 안전 조건을 최초 표시. 전체 추가 질문, 입력된 관찰·근거 ID, 출처·적용 한계, 사례 선택 근거와 주의사항은 접근 가능한 details/summary로 분리.
- web/style.css: 후보 카드, 펼쳐보기/키보드 포커스, 좁은 화면 스타일 개선.
- tests/test_p7_2_step3.py: 안전 조건과 원본 API 계약 보존 검사.
- tests/browser_step3.py: 기존 API 실응답을 브라우저에 주입해 모바일/안전 차단/자세히보기/자료 누락 확인.

## 보존
- 고장 후보와 검토 순서는 변경하지 않음. 작업자 선택 사례 기반 규칙 엔진 유지.
- 긴급 위험 차단은 접힌 영역에 숨기지 않음. 진단 결과 생성 시에만 상세 표시.
- 독립 API, DeepSeek 연결, ML 모델, 기존 출처 자료, Windows 실행 스크립트 미변경.
- 기존 1·2단계 증상 추천 및 안전 상태 안내 포함.

## 검증
- pytest: 105/105 통과
- Chromium UI: 기존 40 + 1단계 22 + 2단계 28 + 3단계 32 = 122 확인 통과, JS 오류 0.
- 로컬 HTTP: 12/12 통과.
- Chromium은 localhost 직접 연결 대신 FastAPI TestClient의 실제 API 응답을 라우팅했음.
- Windows 사용자의 최종 실행 검증은 미실시. DeepSeek 실제 호출과 ML 실데이터 학습은 미완료.
