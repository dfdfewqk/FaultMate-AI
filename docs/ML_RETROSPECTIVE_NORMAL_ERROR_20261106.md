## ML 완료까지 객관적으로 남은 것

1. 기존 정상 베어링 K001–K006은 **전부 과거에 분석/시험에 노출**. 아직 처음 보는 검증된 정상 물리 베어링 원본이 없음. 공용 데이터에서 같은 80개 조건/다른 구간으로 재분할해도 새 표본이 아님.
2. 다른 대학/실험실의 출처는 모터 전류·진동 채널, 표본율/4운전조건/물리 베어링 ID/라이선스가 일치한다는 실증 근거 없음. 차이가 크면 별도 모델/별도 검증 연구가 필요함.
3. 원 MAT 진동·전류 값의 **원본 SI 보정 계수는 출처 확인 전**. 12특징 무차원 연구 모델을 기존 `vibration_rms_m_s2`·`current_rms_a` 등 3특징 SI CSV 추론 경로에 강제 연결할 수 없음.
4. 최초 사용 전 사전 고정된 외부 독립 정상·손상 베어링 평가 및 표본별 신뢰구간·현장 품질/안전 검토, 데이터 상업적 사용권(기존 Paderborn **CC BY-NC 4.0**)이 필요.
5. 따라서 **현 버전의 원본 RAR 연구용 분석만 유지**하고, `/api/ml/inspect`의 생산 ML은 계속 `unavailable`로 차단. 오류가 아니라 증거 부족으로 의도된 차단임.

**최종 판단:** 이번 작업에서 ML 평가 코드/원본 재현/사후 정상 오경보 측정을 실제 수행한 것은 완료. 산업현장용 ML 모델의 *최종 완성*은 아닐 뿐 아니라, 현재 증거로는 승인하는 것이 부적절.
