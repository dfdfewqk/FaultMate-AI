## 사용자 Windows 1회 최종 확인

1. ZIP 압축 해제 후 `FaultMate-AI/start_windows.bat` 실행. Python 3.10+ 및 패키지 최초 설치용 인터넷 필요.
2. 증상 입력 → 관련 사례 직접 선택 → 관찰 항목 확인 → 원인 후보 표시 → 요약 복사.
3. 긴급 위험 `있음` 선택 → 기존 결과 삭제와 진단·AI·ML 차단 확인.
4. 근거 자료실 펼치기 → 사례 열기와 상세 출처 확인.

Windows에서 이 최종 수정본을 직접 실행해 보지는 못함. 테스트에서 발견되는 Windows 전용 문제는 이 문서에서 완료로 판정하지 않음.
