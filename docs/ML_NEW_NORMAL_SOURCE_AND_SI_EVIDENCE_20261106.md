# FaultMate ML — 새 원본 자료 / SI 보정 근거 확인 및 안전한 입력 준비 (2026-11-06)

## 판정

**이번 단계에서 실제 해결한 부분은 "새 원본이 도착하면 동일 파일인지 해시로 확인하고 기존 연구모델과의 입력 불일치를 자동 차단"하는 실행 코드와 검사다.** 새로운 독립 정상 베어링 원본을 실제로 다운로드하여 물리 개체·라벨·채널까지 확인하거나 Paderborn 저장 수치의 SI 단위를 입증했다는 주장은 **하지 않는다**.

- 실측 Paderborn 사후 평가(PR #47)는 이미 열린 정상 6개/손상 6개에 대한 연구용 LOBO이다. 정상 6/6·손상 5/6은 새 코호트 시험이 아니고 생산용 ML을 승인하지 않는다.
- 원래 Paderborn 출처는 **정상 물리 베어링 6개**, 손상 26개, 각 4조건×20기록, 동기화된 진동+모터전류 데이터를 공식 공지: https://mb.uni-paderborn.de/en/kat/research/bearing-datacenter/data-sets-and-download .
- Paderborn 원본은 **CC BY-NC 4.0**, 비상업 이용만 공개 허가: https://mb.uni-paderborn.de/en/kat/research/bearing-datacenter .
- 원 MAT 파일에 저장된 \`Y.Data\`의 실제 SI 단위·계수/전류 센서 영점 오프셋은 기존 확인 자료로 미입증. 수치가 빈 \`Unit\` 메타데이터만으로 가속도 m/s² 또는 전류 A라는 주장은 할 수 없다. 원본 출처의 특정 장치/센서 설명만으로 저장 값의 단위가 입증되지 않는다.

## 새로 확인한 출처: HUST 실험실 베어링 (Paderborn과 **다른 도메인**)

출처: [2023년 HUST 논문](https://doi.org/10.1186/s13104-023-06400-4), [Mendeley Data v3](https://data.mendeley.com/datasets/cbv7jyx4p9/3). 원저자 공개 설명은 **3개 정상 물리 베어링 / 27개 손상 시제품** 및 총 99개 진동 기록·51.2kHz·3개 부하 조건을 기술한다. 공개 라이선스 **CC BY 4.0**.

**중요:** 이 자료가 Paderborn 연구 모델과 동일한 원시 진동+전류 64kHz·4조건×20쌍을 제공한다는 근거는 없다. HUST 논문은 **진동 전용** 신호를 제공한다. 서로 다른 연구의 정상 개체가 존재한다는 사실은 맞지만, 이를 현재 12무차원 특징(진동 6 + 전류 6) 연구모델의 "독립 정상시험 3개"로 돌리는 것은 기술적으로 잘못된 검사이다.

HUST 데이터를 실제 평가하려면 **별도의 진동 전용 모델과 새 사전등록된 물리 베어링 그룹 분할·출처 검증**이 필요하다. 정상 개체 3개만으로 안전 필수 산업용 오경보율을 입증하기도 어렵다. 따라서 현재 모델 재학습/현장 활성화 자동 수행은 금지한다. 데이터 유입 전에 원본 아카이브의 실제 SHA, 원저자 파일명·물리 개체 ID, 건강 상태 라벨과 저자 문서 대응을 확보해야 한다.

## 이번에 실제 만든 코드

- \`scripts/verify_new_bearing_original_files.py\`: 고정된 원저자 URL/라이선스/센서 채널과 신규 자료의 **실제 바이트 SHA256** 대조. 원본 파일이 이미 이전 베어링 ID를 사용했다면 차단; 중복 동일 원본을 두 물리 개체라고 기재하면 차단; 경로 탐색/심볼릭 링크/원본 바이트 변경 차단.
- 자료가 일치해도 **원본 파일 바이트 확인과 원저자 물리 개체/정상·손상 라벨 확인은 별개**임을 명확히 결과로 분리한다. 모델 학습·추론, 물리 SI 보정, DeepSeek 호출, 장비 사용 허가를 수행하지 않는다.
- \`docs/experiments/HUST_UNVERIFIED_SOURCE_INTAKE_CANDIDATE_20261106.json\`: 출처 메타데이터만 기록한 **원본 파일 0개 상태의 미승인 후보 manifest**. 근거 없는 새 건강 베어링 ID나 SHA를 만들어 채우지 않는다.
- \`tests/test_verify_new_bearing_original_files.py\`: 합성 파일로 SHA/경로 침범/시그널 중복/기존 베어링 중복/허위 SI 주장/허위 저자 라벨/무단 승인/기존 결과 덮어쓰기 보호 확인.
- \`.github/workflows/ml-new-source-si-intake-no-go-20261106.yml\`: 후보 manifest에 원본이 없으면 **원본 0개**와 생산 ML 차단을 보고하고 기존 원본 단위·외부 정상 출처 NO-GO 정책을 재검사. 새 데이터를 만들거나 외부 유료 API를 호출하지 않는다.
- 기존 \`scripts/convert_mat_to_csv.py::verify_units\`는 **저장된 실제 MAT 바이트 해시 + 특정 원본 데이터에 대응하는 저자/공식 증거 문서 해시 + 수치 스케일/영점 오프셋 + 검토자/날짜**가 없으면 Paderborn의 공란 단위를 SI로 변환할 수 없게 보호되어 있다. 해당 보호 장치는 유지했다.

## 재현 가능하게 새 자료가 들어오면 할 일

1. 원 출처에서 **공식 원본 파일**을 확보하고 파일 SHA256을 로컬에서 계산한다. 내려받은 파일 경로나 원본 URL만으로 무결성을 증명하지 않는다.
2. 출처 문서의 **물리 베어링 ID 및 라벨**과 실제 파일의 대응 관계를 외부 근거로 확인한다. 조건별 기록 수를 서로 다른 독립 물리 개체 수로 대체해서는 안 된다.
3. 본 코드의 \`--manifest\` (신규 원본별 상대경로·SHA256 포함), \`--original-root\`를 실행해 원본 파일 해시·경로·중복을 검사한다. **합성 테스트에서 통과했다고 실제 베어링 ID/라벨 검증 성공은 아님**.
4. 외부 HUST처럼 채널·속도·조건이 다르면 **별도 도메인의 별도 진동 모델·독립 평가**로 분리한다. 기존 Paderborn 모델의 사후 정확도와 혼합하지 않는다.
5. 원본 Paderborn MAT \`Y.Data\`의 **실제 물리 SI/환산계수/오프셋**에 대해서는 KAt 원저자의 데이터셋별 확인 문서가 필요하다. 모델명·ADC 주파수·센서 감도 일반 사양만으로 단위 승격 금지.
6. 적합한 새 독립 자료 확보 뒤, **처음 분석하기 전에** 건강/손상 물리 개체 수, 분할, 지표, 신뢰구간, 합격 기준을 고정한다. 이 조건이 미충족이면 기존 생산 ML API와 모델의 비활성화를 유지한다.

### 파더보른대 데이터 보관·측정 담당자에게 확인이 필요한 구체 사항

- \`N15_M07_F10_K001_1.mat\` 같은 2016년 원본에서 \`vibration_1.Y.Data\`의 **저장 숫자값**은 m/s², g, volt 또는 ADC counts 중 무엇인지? 별도 감도·증폭/필터 설정이 이미 적용돼 있는가?
- \`phase_current_1.Y.Data\` 숫자값은 A, V 또는 counts인지? 영점 전압·DC 오프셋이 이미 제거돼 있는가?
- 두 신호에 대한 **정확한 수치 단위 변환 계수·오프셋**, 저장 시점 적용 여부, 전체 물리 베어링·4조건에서 동일하게 적용된 범위와 문서 위치.
- 과거 기록 중 미개봉 정상 물리 베어링이 공식 데이터셋의 기존 K001–K006 외에 추가 공개됐는지? 없다면 없음을 문서화해야 한다.

**정리:** 기술적 전처리·실제 파일 무결성 경로 개발 가능 부분은 수행. 새 원본의 공식 신원/라벨 증명과 Paderborn 저장 수치의 SI 값은 외부 원본 데이터/원저자 증거가 아직 없으므로 **완료라고 할 수 없는 과학적 선결 조건**이다. 모델과 학습 데이터·사용자 파일·main은 변경하지 않는다. ZIP·EXE는 요청 전까지 만들지 않는다.
