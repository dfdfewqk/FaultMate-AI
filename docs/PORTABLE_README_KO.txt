FaultMate AI P7.2 — Windows 압축 해제형 실행본

사용법
1) 공식 GitHub Actions에서 제공하는 ZIP을 내려받아 새 폴더에 압축을 풉니다.
2) FaultMateAI 폴더 안의 RUN_LOCAL_ONLY.bat을 더블클릭합니다.
3) 기본 브라우저에서 http://127.0.0.1:8787/ 을 엽니다. 8787 포트가 사용 중이면 콘솔에 표시된 주소를 이용합니다.
4) 종료할 때 콘솔에서 Ctrl+C를 누르거나 프로그램을 종료합니다. 자동 실행/Windows 서비스로 등록하지 않습니다.

안전 범위
- 설치 프로그램이 아니라 압축 해제형이며 관리자 권한을 요구하지 않습니다.
- Python 설치나 실행 중 패키지 다운로드가 필요하지 않도록 패키징했습니다.
- RUN_LOCAL_ONLY.bat은 현재 실행 세션의 DEEPSEEK_API_KEY 값을 제거한 뒤 실행합니다.
- 서버는 127.0.0.1 로컬 주소에만 바인딩합니다. 자동 외부 서버 업로드나 실설비 제어 기능이 없습니다.
- Windows Defender/SmartScreen 경고가 나오면 보안 기능을 끄지 마세요. 배포본 검증이 끝나기 전 실행하지 마세요.
- 프로그램 창이 실행되지 않거나 오류가 있으면 종료하고 검증 기록을 확인하세요.

현재 기능 상태
- P7.2 기본 고장 진단은 교육용 '원인 후보 검토'만 지원합니다. 원인 확정/안전 승인/설비 제어 아님.
- 모델은 아직 승인되지 않았으므로 ML 예측은 기본적으로 사용 불가입니다.
- DeepSeek는 로컬 전용 배치 실행 시 연결되지 않습니다. 유료 API 호출·외부 전송을 진행하지 않습니다.
- 실제 Paderborn 진동·전류 센서 단위 검증 및 실측 모델 훈련은 완료되지 않았습니다.
- 이 배포본은 *포장된 실행파일이 독립 Windows CI 환경에서 검증된 후에만* 공유·사용해야 합니다.
- 상업적 학습 데이터(원본 .rar/.mat), 라이선스 제한 데이터, API 키, 사용자 파일은 이 ZIP에 포함하지 않습니다.

파일 구조
- FaultMateAI.exe: Python 설치가 필요 없는 실행 파일
- _internal: 프로그램에 필요한 기본 의존성/웹 자료. 절대 삭제하지 마세요.
- RUN_LOCAL_ONLY.bat: 외부 AI 키를 비활성화한 채 실행
- README_PORTABLE_KO.txt: 이 문서

배포 검증 기록과 SHA-256은 GitHub Actions 작업 페이지의 출력 로그를 확인하세요.
서명되지 않은 배포본이므로 파일의 출처와 SHA-256을 확인하세요.
