# FaultMate AI P7.2 — 5단계 사용성 개선·디버깅 기록

기준: P7.2 4단계 통합 ZIP. 새 별도 사본에만 반영. 원본과 기존 사용 데이터 변경 없음.

## 변경 사항
1. 원인 후보 검토 성공 시에만 '진단 요약 복사' 표시. 설비·관찰 증상·후보·우선 확인 기록·안전 조건·중단/보고 기준을 짧은 일반 텍스트로 복사. 우선순위나 고장 확정이라고 표현하지 않음.
2. 복사 본문에 '원인 미확정', '정비 작업 허가 아님', 'AI/ML 결과 미포함', '가상 데이터 여부'를 명시. 모델명·알람 원문과 내부 API·출처 ID는 기본 복사에서 제외.
3. 클립보드 복사는 버튼 클릭 시에만 시도. 권한 거부·브라우저 미지원에 대한 실패 문구를 표시. 실패 시 별도 외부 전송이나 서버 저장을 시도하지 않음.
4. 입력 편집·초기화·긴급 위험 선택 시 이전 복사 버튼도 제거. 제출 당시의 값으로 결과/요약을 생성하여 편집 중 문맥 뒤섞임 방지.
5. 첫 화면 상단 중복 AI 연결 상태 제거; 기존 연결 상태와 AI·ML 도구는 '고급 분석' 접힌 영역에 유지.
6. 기존 진단 엔진, 안전 차단, 사례 7개/출처 8개, AI 동의 인터페이스, ML CSV·추론 API와 P7.2 1~4단계 기능 변경 없음.

## 검증
- Python 전체 회귀: `python -m pytest -q tests`
- JS 구문: `node --check web/app.js`
- Chromium UI: `browser_smoke.py`, `browser_step1.py` ~ `browser_step5.py`
- 로컬 실제 HTTP: `live_http_smoke.py`
- 별도 폴더 ZIP 압축 해제 후 재검사

한계: Chromium 테스트는 로컬 직접 접속 대신 FastAPI TestClient 응답 라우팅. 클립보드는 자동화 브라우저의 복사 성공·실패 모의 콜백 검증이며 Windows PC OS 클립보드 종단 검증은 아님. 실제 DeepSeek 원격 호출 및 ML 실제 실측 학습은 미완료.

다음은 6단계 최종 회귀·Windows 사용 점검만 남으며 이 단계에서 신규 설계·기능 확장은 진행하지 않음.
