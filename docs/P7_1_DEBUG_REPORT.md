## 2. 실제 확인·수정한 결함

1. **CSV 파서 예외**: 256KB 제한보다 작은 CSV라도 한 필드나 헤더가 Python CSV 파서 한도를 초과하면 HTTP 500 예외가 발생했음. 초과 헤더/필드를 검증 오류(`unsupported_input`)로 안전하게 처리하도록 수정.
2. **비동기 ML 결과 경합**: 업로드 파일을 바꾸거나 긴급 위험을 선택했을 때 이전 분석 결과가 나타날 가능성 방지. 이전 요청 취소·응답 버전 검증·결과 무효화 적용.
3. **긴급 위험에서 ML 버튼 활성**: 안전 차단 화면에서는 고급 ML 분석도 중단하도록 수정. 위험 해제 시 필요하면 다시 분석할 수 있음.
4. **AI 미리보기 재생성 시 동의 유지 가능성**: 새 미리보기 요청마다 기존 동의를 해제하고 이전 결과를 제거. 늦게 도착한 미리보기 응답은 무시.
5. **잘못된 URL 해시**: 주소에 잘못된 퍼센트 인코딩이 들어오면 화면 초기화가 중단될 수 있던 부분에 보호 코드 추가.
6. **상태 표기 불일치**: `ml_model=not_included`를 `unvalidated`로 교정. `ui_release=P7.1` 추가. 기존 규칙 엔진 계약의 `phase=P2`는 호환을 위해 유지.
7. **비정상 ML 모델 JSON**: 예상하지 못한 JSON 자료형은 `unavailable`로 처리해 모델 상태 조회 예외 방지.

## 4. 남은 일 (우선순위)

1. **사용자 Windows P7.1 실행 1회**: 압축 해제 후 `FaultMate-AI/start_windows.bat`. 진단 1회·위험 차단·초기화 정도만 확인. 반복적 수동 테스트는 필요하지 않음.
2. **Antigravity: 공개 실측 데이터 변환 및 실제 베어링 모델 실험**: 출처·단위·라벨·라이선스 확인 후 학습·독립 평가. 모델 승인은 검증 이후에만.
3. **Antigravity: 실제 DeepSeek 통신 검증**: 환경변수로 키 연결. 동의 전 요청 0회, 동의 시 요청, 오류 시 로컬 엔진 유지. 키 유출 금지.
4. **최종 통합 검증**: 실환경 AI·ML 활성화 시 안전 차단·오진 위험·현장 적용 범위를 재점검.
