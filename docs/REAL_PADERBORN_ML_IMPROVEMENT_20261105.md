## 확정적으로 보존한 데이터 경계

- 개발 자산만 사용: 정상 **K001/K002/K003/K004/K005**, 손상 **KA04/KA16/KB23/KI04/KI16**.
- 기존 봉인 시험에 이미 사용한 **K006·KI18은 다운로드하지 않고, 모든 후보 선택·새 실험·모델 적합·성능 평가에서 제외**.
- 정상 400개 + 손상 396개 = **796개 실제 고유 진동/전류 신호 특징 기록**만 비교에 사용.
- KA04 동일 원시 신호 중복 4개 제외. 실제 학습 단위는 기록 796개가 아니라 **서로 다른 물리 베어링 10개**.
- 기존 원본 감사 MAT SHA256/신호 SHA256, 공식 원본 체크섬, 실측 학습 성공 결과의 특성 보고서 SHA256과 **별도로 다시 대조**. 감사 당시 목록 파일의 해시는 그 당시 두 원본 감사 산출물끼리 비교하고, 현재 데이터 목록의 베어링 ID·공식 MD5·라벨을 다시 확인한다. 목록 문서의 본문 변경만으로 실측 파일이 변조됐다고 오판하지 않는다.
- 마지막 외부 2개 시험 베어링은 이미 기존 모델 평가 때 결과를 확인했으므로 **추가 모델을 그 위에서 다시 테스트하여 새로운 독립 평가라고 주장하지 않음**.

## 발견된 4건의 오류

기존 모델은 각 측정 기록을 별도 샘플로 학습한 로지스틱 회귀이며, 베어링당 전체 가중치를 같게 정한 뒤 시험 베어링의 기록별 예측값 중앙값으로 판단했다.

| 베어링 | 정답 | 기존 실측 모델 예측 | 기존 손상 점수 |
|---|---|---|---:|
| K002 | 정상 | 손상 (오경보) | 0.53355 |
| K004 | 정상 | 손상 (오경보) | 0.58400 |
| K005 | 정상 | 손상 (오경보) | 0.73523 |
| KI04 | 손상 | 정상 (미탐) | 0.47499 |

개선 원리는 원시 신호의 절대 진폭을 임의로 해석하는 것이 아니라, **동일한 물리 베어링에서 4개 운전 조건에 걸쳐 얻은 무차원 특징을 베어링당 중앙값 벡터 1개로 요약하고, 이 베어링 단위에서만 학습·판단**하는 것이다. 기존 구조보다 실험 기준을 실제 독립 평가 단위에 맞춘다. 다만 학습 데이터 수가 10개이므로 과적합 위험은 여전히 크다.

## 실제 10개 개발 자산 Leave-One-Bearing-Out 결과

사전 고정 후보 4개와 결정 기준 0.5를 동일한 출처 데이터·베어링 단위로 비교했다.

| 실험 후보 | 개발 LOBO 정확도 | 개발 LOBO Macro-F1 | 오경보 | 미탐 |
|---|---:|---:|---:|---:|
| 이전 기록별 로지스틱 회귀 (12개 특징) | 60% (6/10) | 0.5833 | 3 | 1 |
| **개선: 베어링별 중앙값 로지스틱 회귀 (12개 특징)** | **100% (10/10)** | **1.000** | 0 | 0 |
| 베어링별 중앙값 로지스틱 회귀 (스펙트럼 6개 특징) | 100% (10/10) | 1.000 | 0 | 0 |
| 베어링별 중앙값 스펙트럼 최근접 중심 분류 | 100% (10/10) | 1.000 | 0 | 0 |

10개 개발 자산 **안에서만 다시** 후보를 선택하는 중첩 개발 LOBO의 결과 역시 10/10이었지만, **후보군 자체를 기존 오류를 보고 고른 탐색적 실험**이므로 새로운 사전등록·블라인드 시험이나 독립 외부 검증이라고 말하지 않는다.

### 운전조건별 데이터만으로 같은 베어링 수준 검사를 했을 때

| 사용한 한 가지 운전조건 | LOBO 정답 | 오경보 | 미탐 |
|---|---:|---:|---:|
| N09_M07_F10 | 9/10 | 0 | 1 (KI04) |
| N15_M01_F10 | 9/10 | 1 (K005) | 0 |
| N15_M07_F04 | 10/10 | 0 | 0 |
| N15_M07_F10 | 9/10 | 1 (K005) | 0 |

전체 4개 운전조건을 합산할 때 점수가 개선됐지만, 한 조건만 분석하면 동일한 오류가 일부 재발한다. 따라서 **적은 수의 센서 기록 한 건만 받아도 같은 성능이 나온다고 주장하지 않는다.** 이 실험 모델을 사용한다면 4개 운전조건 및 충분한 기록이 필요한 별도 입력 계약과 외부 검증이 선행돼야 한다.

## 왜 아직 '완성된 ML'이 아닌가

1. **개발용 자산 10개만으로 고른 개선 방법이므로** 10/10은 새 데이터 정확도 100%가 아니다. 더 많은 **처음 보는 독립 물리 베어링**의 사전 고정 시험이 필요하다.
2. 원래의 **K006/KI18 2개 시험 베어링은 이미 이전 모델을 시험해 공개된 결과가 있으므로** 새 모델의 독립 시험용으로 다시 쓸 수 없다.
3. 센서 숫자의 실제 SI 보정 근거가 없으므로 이상 징후 물리값 해석/범용 설비 진단에 사용하지 않는다. 무차원 특징의 소규모 정상·손상 연구 결과로만 취급.
4. **현재 FaultMate AI API의 기존 검증모델 로더는 12개 입력에 베어링 전체 집계를 요구하는 이 신규 모델과 입력 계약이 다르다.** 계수를 파일명만 바꿔 로드하는 것은 금지.
5. 실제 생산·작업자 안전 관련 점검은 OEM 매뉴얼·사업장 절차 우선. 모델이 고장을 확정하거나 안전 허가·자동 제어를 하지 않는다.
