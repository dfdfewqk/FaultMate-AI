# FaultMate AI — 이미 검증했던 KI21 손상 베어링의 실제 미탐 재현·신뢰성 경계 (2026-11-06)

## 결론

실제로 Paderborn 원본 손상 베어링 **KI21.rar**의 공식 MD5·원본 MATLAB 80회 진동/전류 데이터를 다시 확인하고, 기존에 얼려둔 12개 무차원 특징 기반 ML로 예측했더니 **손상 자료를 정상으로 오판**하는 결과가 재현되었다.

- 원저자 실측 손상 정답: **damaged** (Lessmeier et al., 2016, Table 5)
- 동결 모델의 출력: **healthy**
- 같은 원본·고정 기준 점수: **0.45992558**, 손상 임계값 **0.5**
- 원래의 신규 손상 베어링 8개 평가: **7개 손상 검출 / KI21 1개 미탐**.
- **이번 KI21 실험은 이미 열어본 같은 베어링을 다시 실행한 것**이므로 9번째 새 시험이 아니다. 개선·학습·임계값 조절도 하지 않았다.
- 실제 원본 KI21 재검증과 결과: [GitHub Actions — 2026-11-06 원본 자료 재현](https://github.com/dfdfewqk/FaultMate-AI/actions/runs/42136869978).

## 이번 개발

- `scripts/replay_prior_damaged_bearing.py` — 사전등록된 8개 **과거 시험 손상 베어링 ID와 공식 MD5**를 사용하고 기존 `extract_unseen` 검사·80회 MAT·진동/전류 특징·SHA/중복 판단·고정 모델 계수를 재사용. **출처 원본 파일을 직접 검증한 실행에서만** 원본 인증 성공을 보고한다. KI21의 정상 오판이 재현되지 않으면 동결 모델/전처리 변경 가능성을 의심하고 실패 처리한다.
- `faultmate/integration/research_raw_archive.py` — 기존 12개 원본 연구 자산 + **이미 열어봤던 추가 손상 8개**만 원본 `.rar` 연구 API로 허용. 알 수 없는 베어링이나 원본·모델 해시 변경은 거절. 손상 정답/예측/기존 미탐 여부, **과거 시험 재현—not 새 시험** 구분 필드를 화면에 전달한다.
- `web/app.js` — 실제 손상인데 모델이 정상으로 판단했다면 **"실제 손상 베어링을 정상 쪽으로 잘못 예측한 미탐"** 경고와 **"운전·작업 안전 판단 금지"**를 분명하게 표시. 일반 점수는 절대 정비 승인/고장 확정으로 표현하지 않는다.
- `tests/test_known_damaged_replay.py` — 모두 **합성 특징을 쓰는 코딩 단위테스트**, KI21 반대 점수/변조된 진위·출처 해시/80 MAT 누락/중복 특징/기존 8개 vs 신규 베어링 구분, 이미 알고 있는 KI21 실패를 조용히 성공으로 바꿔치기 금지.
- `tests/windows_native_browser_acceptance.py` — UI 경고 렌더링은 **합성된 KI21 API 응답을 브라우저에 주입**하는 방식으로 테스트. 합성 표시 검사 자체를 실측 결과로 주장하지 않는다. 실제 원본 소스 검증은 별도 원본 데이터 검사로 수행한다.
- `scripts/check_known_ki21_real_failure.py` — **실제로 다운로드한 KI21 원본 파일의 MD5 확인 → 프로그램 원본 RAR API에 80MAT 전부 다시 입력 → 정상 오판 재현·경고·정식 ML 비활성화 여부 확인**.
- `.github/workflows/stage7-known-damaged-ki21-replay.yml` — 기존 Linux·Windows·Chromium/원본 K001 회귀 + **별도의 실제 KI21 원본 재실행** 작업 추가. CI와 파일은 사용자 실제 데이터·main·기존 실측 모델을 변경하거나 유료 DeepSeek를 호출하지 않는다.

## 남은 현장 ML 신뢰성 조건

새로운 **사용한 적 없는 독립 정상 물리 베어링**, 출처·센서·운전조건 호환성, 실제 SI 센서 단위, 원본 데이터 사용 라이선스 및 서비스 환경을 확보하지 못했다. 따라서 **새 독립 정상 베어링의 특이도/오경보율·실제 현장 정확도**는 미측정이고, 현재 모델의 정식 사용 승인은 금지한다.

분석 모델은 교육·연구용이고, 기존 회사 설비에 사용하는 3개 SI 특징 CSV 정식 ML API는 계속 비활성이다. ML이 어떤 설비의 운전 지속 또는 정비 작업을 허가하는 기능도 없다.

**모델 계수, decision threshold 0.5, 원본 사용자 RAR/MAT/SQLite, main, DeepSeek 유료 연동 및 EXE·ZIP 배포를 그대로 유지**한다.
